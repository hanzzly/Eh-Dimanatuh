# Auto EngDis (Modified Edition)

Unofficial Bot EngDis API.
*Originally created for KMITL students, now modified to work with SMK Telkom Malang's English Discoveries system.*

## Fitur
- Auto-login menggunakan API English Discoveries khusus (SMK Telkom Malang).
- Menyelesaikan soal-soal *Test* secara otomatis dengan panduan kunci jawaban langsung dari server (Nilai 100).
- Menandai modul *Practice* dan *Explore* sebagai selesai (Progress 100%).
- Fitur auto-logout dengan aman setelah tugas selesai.

## Cara Penggunaan

1. Pastikan kamu sudah menginstal [Node.js](https://nodejs.org/).
2. Buka terminal di dalam folder proyek ini.
3. Install semua *package* (dependensi) yang dibutuhkan dengan perintah:
   ```bash
   npm install
   ```
4. Jalankan bot menggunakan perintah:
   ```bash
   node .
   ```
5. Saat diminta di terminal, masukkan **Username** dan **Password** akun English Discoveries kamu.
6. Bot akan otomatis login, memilih *course* kamu, dan mulai menyapu bersih soal-soal!
